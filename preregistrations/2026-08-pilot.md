## Status

This is the **v0.1 metric-validation pilot**, not a publishable effect-size round. It has 12
prompts, below the 25-prompt floor set in `METHODOLOGY.md` §5.2. It is powered to validate
metric reliability (H1) and estimate variance components (position, model, format, condition)
to size Round 1 — **not** to publish an effect size for H4. See "Reporting rules" below.

## Design

- **Conditions:** `control`, `treatment` — paired within prompt; only the target document
  differs, the other 5 are byte-identical between arms.
- **Runs per cell:** 24. Not arbitrary — split-half reliability on mock data crosses the usable
  threshold (Spearman-Brown ≥ 0.7) between n=16 and n=24, and plateaus after. Do not use 10.
- **Temperature:** 1.0, fixed. Measures the distribution a real user is exposed to; not to be
  lowered to stabilize numbers.
- **Document order:** randomized per run, seeded deterministically from `(corpus_version,
  run_key)`. Reproducible from the seed alone; this is what makes PSI estimable at no extra cost.
- **Total calls:** 8 models × 12 prompts × 2 conditions × 24 runs = **4,608**.

## Hypotheses

As defined in `METRICS.md`:

| ID | Hypothesis | Falsified if |
|---|---|---|
| H1 | CPR is reliable enough to measure at n=10 runs | Within-condition ICC < 0.5 across most models |
| H2 | Position effect (PSI) is large — comparable to or larger than content effects | PSI < 0.05 across models |
| H3 | Cross-model agreement on citation-worthiness is low | Kendall's W (within-model-baselined) > 0.7 |
| H4 | Extractable-claim density causally raises CPR (Profound's specificity claim) | Paired effect CI includes zero |
| H5 | Metrics behave consistently across content formats | Format × model interaction dominates main effects |

H2 and H3 are the ones worth running for: both are cheap, both are things no incumbent vendor
has an incentive to publish, and either result is interesting.

## Primary metric

**Citation Presence Rate (CPR)** — A1 in `METRICS.md`. Proportion of runs in which the target
document is cited. Reported per model with a Wilson 95% interval.

## Analysis plan

Fixed in advance, executed by `analyze.py --runs results/runs.jsonl`:

- **A1 CPR** per model, Wilson 95% CI.
- **H2 / D1 PSI**: max−min citation rate across presentation slots, per model and pooled;
  significance via permutation test shuffling slot labels within model.
- **H4**: paired per-prompt (treatment − control) CPR delta, sign-flip permutation test on the
  per-prompt differences, bootstrap CI on the pooled delta. Reported per model and pooled.
- **H3**: Kendall's W on document citation-rate rankings, cross-model vs. a within-model
  split-half baseline computed the same way. Only the gap between them is evidence of real
  cross-model disagreement — raw cross-model W is not read on its own.
- **H1**: split-half, Spearman-Brown-corrected reliability of CPR per model, plus the pooled
  reliability-vs-runs-per-cell curve (used to size Round 1).
- **H5**: CPR by content format, and an eta² variance decomposition across model, prompt,
  position, format, domain, and condition — the number that says where a hypothetical
  optimization effort should go.
- All inference is permutation- or bootstrap-based (RNG seed `20260811`, fixed in `analyze.py`).
  No scipy/statsmodels, per the stack constraints in `CLAUDE.md`.

## Reporting rules

- **H4 is reported as an interval and a variance estimate, not a finding.** 12 prompts is below
  the 25-prompt floor; this round is not powered to publish an effect size.
- Any model with a high no-cite (unparseable-citation) rate is **excluded, not averaged in** —
  check the DATA HEALTH section of `analyze.py`'s output before trusting anything else from
  that model. A high no-cite rate is an instruction-following failure, not a low-visibility
  signal.
- `model_returned` is checked against the requested model on every run before cross-run
  comparison; a silent reroute invalidates comparability for that cell.
- Nulls are published with equal prominence to any positive result.

## Stopping rule

- **Fixed-n, not sequential.** All 4,608 cells run to completion (or resumed via `--resume`
  after interruption); no early stopping based on interim effect sizes.
- The round counts as complete when `results/runs.jsonl` has **<2% error rate** across cells
  (per `ROADMAP.md` item 3) and `model_returned` has been checked for unexpected substitutions.
- If a single model's error rate exceeds ~10% (persistent rate-limiting or 4xx/5xx), exclude
  that model from the round rather than retrying indefinitely, and document the exclusion
  explicitly in the analysis — do not silently drop it.

## Deviations

Any deviation from this plan — an added intervention, a changed model list, a different
runs-per-cell count — is logged here with a timestamp before analysis, not made silently.
