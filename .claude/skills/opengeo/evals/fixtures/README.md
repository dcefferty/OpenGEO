# Test fixtures

Fictional pages written to test the `opengeo` skill: a Tucson plumber's water-heater page,
the same page with prices added, and four competitor pages. Any resemblance to a real
business is coincidental. `edited_length_block.html` deliberately changes the length by
more than three words, to test how the skill handles the tool's length check.

`results-running-shoes/` is the output of a real `opengeo test` run: corpus v0.4's
`cons_shoes` question, fed through the command to check it reproduces the published
result. `runs.jsonl` is omitted for size; the report, chart, corpus and manifest are the
real files.
